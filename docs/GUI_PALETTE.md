# GUI 配色：Nord 参考与测量

参考：[Nord 官方 Colors and Palettes](https://www.nordtheme.com/docs/colors-and-palettes/)，查阅日期 2026-10-20。

这是一套基于 Nord 的界面适配，不是对某个 Nord 应用截图的像素级复制。官方发布 16 个不透明色值，没有统一的界面透明度规范。下面的透明度、阴影以及浅色文本加深值是本项目的适配参数。

## 映射原则

- 大面积使用 Polar Night / Snow Storm；Frost 用于选中项、链接、主要操作。
- 实色方案作为基础回退；当前版本加入外层毛玻璃，见下方“毛玻璃细化”。输入框、表格容器和指标卡继续保持不透明。
- Aurora 颜色仅用于成功、警告、错误，避免与导航强调色混用。
- 浅色模式的主色 #48678e 是 Nord #5e81ac 的加深适配；状态文字也加深。深色成功文字调亮为 #b9d2a5、错误文字调亮为 #edb0b7，保证小字可读。
- #f6f8fa 输入框、#7b8698 / #8b97ab 控件边框、#9ccbd8 悬停色也是适配色，不标称官方原色。
- 文字整体 opacity=1；禁用按钮 opacity=0.5，状态圆点 opacity=0.75。文字不再靠透明度弱化。
- 阴影为中性灰：浅色 4% / 5% / 9%，深色 8% / 12% / 18%，分别用于小组件、卡片和悬停。
- 不改变业务流程与页面内容，保留原有断点和 reduced-motion 支持。

## 毛玻璃细化（当前版本）

沿用 Nord 色值，透明度仅作用于背景，文字 opacity 保持 1。

| 表面 | 浅色不透明度 | 深色不透明度 | 模糊 | 饱和度 |
| --- | --- | --- | --- | --- |
| 外层卡片、版本铭牌 | 62% | 68% | 36px | 110% |
| 顶栏、分区导航、保存栏 | 76% | 82% | 36px | 110% |
| 内部数据卡、表格容器 | 48% | 54% | 继承外层视觉模糊，不额外叠加 | 不变 |

- 背景加入低强度 Nord 蓝/青静态径向渐变，让玻璃产生轻微底色变化，没有持续动画。
- 上边缘使用浅色 72%、深色 14% 的 1px 内高光，并配合柔和的中性阴影。
- 玻璃导航局部强调色为浅色 #2e4059 / 深色 #d8eef4，避免滚动经过内容时降低文字对比度。
- 仅在外层表面启用模糊，不在嵌套卡片或表格行重复叠加。
- 通过 feature query 渐进启用；不支持 backdrop-filter 的浏览器保留实色。
- reduced-transparency / forced-colors 模式关闭毛玻璃和背景渐变；打印不启用玻璃增强层。
- [新增测量记录](design/nord-glass-measurements.json)检查了卡片基础底色及蓝、青、紫三种色场端点、导航纯黑/纯白极端底色，共 36 组文字配对，最小值 4.93:1。此计算不模拟模糊及饱和度逐像素处理，也不等同于所有嵌套状态组合的无障碍认证。
- 之前的色卡、JSON 和截图作为实色基线保留；当前玻璃截图以 nord-glass 开头。


### 通透度第二轮细化（历史）

- 卡片不透明度由 76% / 82% 下调到 58% / 66%，模糊由 16px 增至 28px。

- 浅色普通链接和装饰字微调为 #446287；玻璃导航的辅助文字采用 #303b4d / #eceff4，防止透出内容后对比度下降。
- 当前玻璃测量 JSON 已更新；上方实色基线表格及 nord-measurements.json 保留原方案参数。

### iOS 材质与控件细化（历史）

参考：[Apple HIG — Materials](https://developer.apple.com/design/human-interface-guidelines/materials)，查阅日期 2026-10-20。借鉴导航浮于内容之上的层级关系，不声称复刻原生 Liquid Glass 的动态折射。

- 顶栏离屏幕顶部 12px，左右留白，采用 28px 圆角的悬浮玻璃容器。
- 主导航与操作按钮采用胶囊轮廓；内容外层 26px、内层 18px、输入框 12px，形成一致圆角层级。
- 顶栏、分区导航及保存栏加入低强度斜向反光和细边高光；内容玻璃保持上一轮色彩及透明度。
- 标题和数值改用系统无衬线字体与较明确字重，减少装饰字体对信息扫描的干扰。
- 主导航点击区至少 44px 高；800px 以下导航采用三列两行，分区导航恢复普通文档流。
- 调整桌面锚点留白，避免内容标题被两层浮动导航覆盖。
- 原始玻璃对比度 JSON 测量不包含新增反光渐变；不会将它表述为当前每个像素的实测。

### iOS 风格控件细化（历史）

- 主按钮：胶囊外形、12% 顶部渐变高光、细边及浅投影；按下缩放到 98%，减少动态效果时取消位移与缩放。
- 次按钮与历史操作按钮：使用与输入框相同的半透明材质，保持主次操作层级。
- 输入框、下拉框与文本区：底色不透明度 84%，悬停 96%；高光浅色 65% / 深色 15%，无额外嵌套 backdrop blur。
- 通常控件最小高度 46px；历史行内按钮 36px。文字输入、选择框与文本区字号至少 16px。
- 焦点采用实色轮廓与柔和外圈；禁用、只读状态不触发悬停高亮。
- 自绘箭头仅用于收起的单选框。展开菜单仍由浏览器/操作系统绘制；不承诺菜单本身具有毛玻璃效果。
- 多选框保留列表外观；forced-colors 模式恢复原生箭头；减少透明度时输入表面使用实色。
- 使用项目实际 CSS 的独立组件预览验证深浅模式、只读/禁用状态、Tab 聚焦和方向键选择，未修改角色数据。截图：[控件对照](design/nord-ios-controls.png)。

### 导航同源玻璃与折叠布局（当前）

- 外层卡片采用导航同款底色、36px 模糊、110% 饱和度与细边高光；浅色不透明度 62%、深色 68%，均比导航低 14 个百分点。减弱宽幅高光与阴影，避免金属质感。
- 指标卡、属性卡、战斗数据卡、效果卡与表格容器使用导航同色系的 48% / 54% 底色；依托外层已模糊的背景，不重复叠加 blur。减少透明度和强制颜色模式恢复实色。
- 单选下拉菜单使用 appearance: base-select 和 ::picker(select)，浅色 74%、深色 86% 底色，28px 模糊、圆角选项、选中勾选和键盘焦点。支持的浏览器启用玻璃，不支持时保留系统菜单。参考：[MDN customizable select](https://developer.mozilla.org/en-US/docs/Learn_web_development/Extensions/Forms/Customizable_select)。
- Rules 默认仅显示职业选择与应用按钮，所有职业快捷链接和 stress cases 放入默认关闭的 details；移除重复的大型职业导航。
- 38 项测试通过，覆盖筛选、折叠结构、角色 ID 保留及未知职业转义；浏览器验证菜单展开、方向键选择、应用筛选和折叠展开。
- 截图：[折叠布局](design/nord-rules-collapsed.png)、[玻璃菜单](design/nord-glass-picker.png)。

### 内部卡片减重

- 内部数据表面的浅色/深色不透明度从 76% / 82% 降至 48% / 54%，背景透过更明显；文字不透明度不变。
- 移除内部数据卡的外投影，顶部细高光强度从 65% 降至 40%，保留边框和现有悬停位移作为层次及交互提示。外层和导航参数不变。

### 表格与控件阴影统一减弱

- 输入框、下拉框、文本区和各类按钮的投影统一为 0 1px 2px，浅色 alpha 2.5%、深色 6%；边缘高光降低到 24% / 8%。按钮悬停沿用相同投影。
- 表格玻璃容器只保留细内高光，实色回退使用同款轻投影。
- 聚焦外光圈收窄，保留 2px 实色轮廓、悬停底色与按下反馈，兼顾键盘操作辨识。

### 表格底色与分隔线细化

- 支持玻璃的浏览器中，表头改为 62% 不透明度，配合 12px 局部模糊，避免滚动时底下的单元格文字干扰固定表头；不支持时保留实色表头。
- 隔行底色由 35% 降到 16%，浅色分隔线为 8%、深色为 10%；文字、表头字重及悬停提示保持不变。
- 减少透明度、强制颜色及打印模式恢复实色表头和原有分隔线。
